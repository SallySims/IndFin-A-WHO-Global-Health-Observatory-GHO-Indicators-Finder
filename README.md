# IndFin-A-WHO-Global-Health-Observatory-GHO-Indicators-Finder
IndFin is a sentence transformer that retrieves WHO Global Health Observatory (GHO) indicators from plain-language queries. It is a small sentence-embedding model (all-MiniLM-L6-v2, 22M parameters) fine-tuned on machine-generated queries, with hard negatives and base/fine-tuned weight blending.
